Frequently asked

Can I use AGrammarly as my keyboard in other apps?

No. The Keyboard tab is a practice surface inside AGrammarly. The app does not install a system keyboard, so it will not appear in your keyboard list. That is a real limitation, not a setting you need to find.

Is this a grammar or spelling checker?

No, despite the name. AGrammarly suggests replies to messages you receive. It does not check or correct what you write.

Does it use AI?

No. Suggestions come from a pattern set that ships inside the app, combined with the phrasings you have used. There is no language model and no server call.

Does anything I type get sent anywhere?

No. This build has no suggestions service configured, so there is nothing for the app to call. It works fully in airplane mode.

Why are suggestions only in English?

The pattern set that ships with the app is English only. A language picker used to appear in Settings but changed nothing, so it was removed rather than left to imply support that is not there.

How do I delete what it has learned?

Settings › Clear everything learned. It takes effect immediately, and uninstalling the app removes everything too.

Is there a paid version?

No. There are no in-app purchases and no subscription.
